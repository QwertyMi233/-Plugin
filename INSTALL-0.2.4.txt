同学堂助手 v0.2.4 安装与倍速使用说明

一、下载安装
Windows 10/11（64 位）：下载 Tongxuetang-Assistant-Setup-0.2.4-x64.exe，退出旧版本，双击按向导安装。设置默认保留。
Apple 芯片 Mac（macOS 13+）：下载 Tongxuetang-Assistant-0.2.4-mac-arm64.zip，解压，将应用拖到 Applications，替换旧版本。无 Developer ID 签名及苹果公证，按系统安全设置提示处理，不要关闭系统保护。
源码 ZIP 供查看和自行构建，普通使用者不需要下载。

二、设置视频倍速
1. 打开软件首页，在“视频倍速”选择 1、1.25、1.5、2、3、4、8、16 倍，或输入 0.25–16。
2. 点击“保存并应用倍速”。设置会立即保存并发送到当前课程窗口。之后新的视频会自动使用该预设，下次打开软件也会记住。
3. 软件会显示播放器实际倍速，速度不受支持时显示错误；高倍速可能无声。修改倍速无需配置 AI 密钥，也不需要暂停队列。
4. 如果还要启用计时器掌控者，勾选该开关再保存。它会同时改动当前视频页的网页计时器和日期；默认关闭，普通视频倍速仍然可用。
5. 恢复 1 倍：点击“恢复正常播放”。这也会关闭脚本。已经载入的脚本会恢复 1 倍计时，刷新课程页面后完全卸载。需要时先暂停、刷新再继续。

三、脚本说明
指定的计时器掌控者 1.0.62 及 Everything-Hook 0.5.9056 依赖已随包提供，不需要另装油猴。内置的是运行这个特定脚本的支持，不是完整 Tampermonkey 扩展；不支持任意用户脚本和 GM API。脚本没有远程自动更新。
脚本仅在同学堂课程任务页面中含有视频的同源框架运行；不会主动在学校登录页、课程列表和答题页载入。脚本出错时可关闭开关，普通视频倍速仍可单独使用。

四、首次使用课程功能
在 AI 设置保存自己的 API 密钥并测试连接；打开高等讲堂，在软件的课程窗口扫码登录；读取课程或导入链接，勾选后开始。既有 AI、自动加入学习和课程队列功能保留。切勿把学校账户密码或 API 密钥上传公开仓库。
软件关闭后暂停任务，重新打开点击继续。网站登录过期时需要重新扫码。

五、验证范围
已通过 51 项 Node/DOM 自动检查及 Electron 45 本地视频页面测试，涵盖主页面、同源 iframe、脚本真实执行、实际速度读取、恢复正常和首页保存设置。
Windows/Mac 应用已交叉构建，但未在这两类系统实机启动，也未以真实课程验证倍速后的学时记录。课程是否完成仍以学校平台状态为准，不能保证倍速缩短服务端计时。
