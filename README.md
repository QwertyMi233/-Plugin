# 同学堂助手 · 联网 AI 版 v0.1.0

适用于 Windows 上的新版 Microsoft Edge / Google Chrome。同学堂网址为 https://tongxuetang.tongji.edu.cn/ 。这是可安装的测试版，不是浏览器商店上架版本。

## 零基础安装：按顺序做一次

1. **完整解压 ZIP**，例如解压到桌面的 `tongxuetang-assistant` 文件夹。不要直接在压缩包里运行文件。
2. 在 Edge 地址栏输入 `edge://extensions`（Chrome 输入 `chrome://extensions`），打开“开发人员模式”，点击“加载解压缩的扩展”，选择解压后的 **extension 文件夹**。这个文件夹里应能看到 `manifest.json`。不要选 ZIP 或最外层文件夹。
3. 如果电脑没有 Python，从 https://www.python.org/downloads/windows/ 安装 Python 3.10 或更新版本，安装时勾选 **Add Python to PATH**。本软件不需要安装额外的 Python 包。
4. 双击解压目录的 **start-windows.bat**。会出现服务窗口并打开“本机 AI 配置”网页。保持黑色服务窗口打开。
5. 在该网页填入自己的 **OpenAI API Key**，确认模型名称，点击保存。API 密钥可在 https://platform.openai.com/api-keys 管理；API 使用单独计费，本版没有实现 ChatGPT 订阅登录。
6. 点击配置页的“复制连接口令”。回到 Edge/Chrome，点击工具栏的扩展图标“同学堂助手”，将口令粘贴到“联网设置”，点击“保存设置”。这里粘贴的是**连接口令**，不是 API 密钥。
7. 点击“检查本机连接”，再点击“测试云端 AI”。前者检查桥接服务，后者实际请求一次 OpenAI，可能产生少量费用。只有云端测试成功，才能确认你的网络、密钥和模型可用。
8. 在**装有插件的同一浏览器**登录同学堂，遇到统一认证由你扫码。安装插件前已经打开的课程页，需要刷新一次。此处登录状态和此前聊天中的远程浏览器互不共享。
9. 在插件点击“打开高等讲堂”，网站中选择“全部”；回到插件点击“读取当前页”或“读取当前筛选全部页”。也可以粘贴课程链接导入。
10. 勾选课程，点击“开始所选课程”。默认一次最多 3 门、最多 20 次 AI 请求，可以在设置修改。需要先“加入学习”的课程会暂停，请你在网站手动加入后点“继续”。

## 每次使用

先运行 `start-windows.bat`，重新填写 API 密钥（出于隐私考虑，密钥默认只保留在本次服务进程的内存里），再打开插件继续。连接口令会留在本机，通常不必重复复制。关闭服务窗口会中断新的 AI 请求。

运行期间保持浏览器、课程标签和服务窗口打开，电脑不要休眠。首次播放若被拦截，手动点击一次播放，再在插件点击“继续”。插件会按正常速度播放；不会跳到视频末尾、修改播放时长或伪造平台完成记录。

## 工作流程

选择课程 → 打开未完成任务 → 正常播放 → 返回目录核对平台任务状态 → 打开试题 → 识别题干及选项 → 优先使用末尾括号中的有效答案提示 → 无提示题请求 OpenAI → 校验题号及选项 → 自动填写 → 点击交卷并确认 → 核对平台完成状态 → 下一门课。

- 识别单选、多选、判断题。判断题依据页面“正确/错误”文字匹配控件，不根据题目排列顺序猜测。
- 题目发送到在线模型；模型不直接控制浏览器，只返回规定格式的答案。实际网页操作由插件执行。
- 可以在“课程资料”粘贴讲义/笔记。插件仅在播放器提供可读取的标准字幕时收集字幕，不会自动转录视频音轨，也不会让模型实际收听完整视频。
- 页面有有效答案提示时优先使用提示；其余题目使用资料和模型知识。AI 无法确定、答案缺失、题号错配或选项不合法时暂停。即使格式有效，AI 答案仍可能有误。
- 自动交卷默认开启。若关闭，填完后暂停，等你检查并手动交卷；随后在插件点击“继续”。
- 交卷后只等待结果，避免重复点击确认。最终完成以平台课程计数和任务状态为准。
- 同题答案会在扩展本地缓存最多 7 天、最多 500 条。可点击“清除答案缓存”。
- 每批请求通常同时处理一张卷中所有无提示题；“最多 AI 请求数”限制的是提交给本机服务的作答请求数，不包含手动点的云端测试，也不是金额上限。请自行在 API 账户设置费用预算。

## 常见问题

| 现象 | 操作 |
| --- | --- |
| 加载扩展时报错 | 确认先完整解压，再选择包含 manifest.json 的 extension 子文件夹。 |
| 提示无法建立连接 / Receiving end does not exist | 刷新同学堂页面，再读取或继续。确认当前课程页与扩展在同一个浏览器里。 |
| 双击启动后提示找不到 Python | 安装 Python 3.10+ 并勾选 PATH，再重新打开启动文件。 |
| 服务端口被占用 | 关闭上一次打开的服务窗口，再启动一次；本版固定使用本机 18765 端口。 |
| 本机检查成功，云端测试失败 | 检查配置页 API 密钥、API 账户额度、模型权限及电脑能否访问 OpenAI 官方 API。不会自动换第三方服务。 |
| 浏览器询问本地网络访问权限 | 允许你自己安装的同学堂助手访问本机服务，然后重试。 |
| 密钥无效 / 配额不足 / 模型不可用 | 在本机配置页更新密钥或模型，并重新做云端测试。 |
| 出现 iam.tongji.edu.cn | 由你在正常网页完成认证，然后点击插件“继续”。不要把学校密码发给插件或写入资料框。 |
| 暂停后视频仍播放 | 暂停按钮会尝试暂停同源播放器；网页已跳走或没有响应时，请手动暂停视频。 |
| 交卷后停住 | 核对网站是否已交卷、是否出现结果以及目录是否更新。不要反复点击“继续”触发新的 AI 请求。必要时先手动返回课程目录。 |
| 显示目录和数量不一致 | 手动核对任务，网站结构或完成条件可能不同。插件不会用“任务完成”静态提示当作已完成证据。 |
| 浏览器关闭后任务不再运行 | 重新打开浏览器、启动服务、核对登录状态，点击“继续”。软件不会在浏览器关闭时运行。 |

## 已验证与局限

本版根据实际登录后的高等讲堂课程目录、两层同源视频 iframe、试题 iframe 和两阶段交卷确认弹窗适配。已读取并区分平台真实的完成图标与静态提示文字。

自动化检查包含状态机、题目提示解析、答案校验、模拟云端请求和模拟交卷后进度确认、本机 HTTP 认证/来源控制。**模拟测试通过不代表已经在学校完成一整门课。** 未使用真实 API 密钥执行在线模型测试，未在 Windows 实机安装验收，也未执行完整长视频到最终正式交卷的线上验收。当前环境无法启动本地 Chromium，安装后的真实浏览器联调仍需在你的电脑完成。

当前仅支持已观察到的普通视频任务及选择/判断试题。遇到其他题型、付费或协议、验证码、跨域播放器、异常弹窗和页面结构变化时会暂停；未加入课程由你操作。不能保证对高等讲堂所有历史课程都兼容，也不能保证 AI 正确率。

## 数据与密钥

- 不读取或保存学校密码；沿用你在浏览器中的登录状态。扩展只在同学堂域名注入脚本。
- OpenAI API 密钥默认仅在本机 Python 服务进程内存中；可选环境变量 `OPENAI_API_KEY` / `OPENAI_MODEL` 用于熟悉命令行的用户。
- 连接口令保存在 `%LOCALAPPDATA%\TongxuetangAssistant\connection-token.txt`，扩展中保存口令副本。它只授权本机桥接，不是学校密码，也不是 OpenAI API 密钥。不要分享此口令。
- 课程题目、选项、你粘贴的资料及可读取字幕会通过 HTTPS 发送到官方 OpenAI Responses API；请求设置 `store:false`，这不等同于承诺所有平台日志都完全不保留。服务绑定 `127.0.0.1`，不会向局域网开放。
- 扩展本地保存课程队列、运行记录、答案缓存和你填写的资料。移除扩展可移除这些数据；连接口令文件需自行删除。
- “导出记录”不包含连接口令和原始资料；“页面诊断”包含当前课程页面上的题干选项和网址，请自行决定是否分享。

## 包内文件

`extension/` 是浏览器扩展；`backend/` 是本机 AI 桥接与配置页；`start-windows.bat` 是启动入口；`tests/` 是开发验证用例，普通使用不必执行。

开发者可运行 `node --test tests/*.test.js` 与 `python -m unittest discover -s tests -p "test_*.py"`。无需构建工具即可加载扩展。默认模型可在本机配置页修改。
