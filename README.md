# 同学堂助手 v0.2.4

Windows x64 与 Apple Silicon Mac 桌面应用。此版在首页加入视频倍速设置，并内置指定的计时器掌控者 1.0.62 和它的 Everything-Hook 依赖。无需另外安装油猴扩展。

## 新功能与使用

1. 打开软件首页“视频倍速”，选择常用速度，或在输入框填写 0.25–16。
2. 点击“保存并应用倍速”。当前视频会应用该速度，后续章节和重启软件后继续使用。修改倍速不需要 AI 密钥，也不会暂停正在运行的课程队列。
3. 如需同时加速网页计时器，勾选“启用计时器掌控者”，再保存。此开关默认关闭；普通视频倍速单独生效。计时器脚本会改动当前视频页的定时器、Date 及视频属性，可能影响播放器行为。
4. 点击“恢复正常播放”会保存 1 倍并关闭脚本。脚本已加载时先恢复 1 倍计时，刷新课程页才完全卸载已安装的钩子。
5. 首页显示播放器实际倍速。浏览器拒绝设置时会显示错误。16 倍是可配置上限，不保证所有播放器都接受；高倍速可能没有声音。

脚本仅在同学堂课程任务页中包含视频的同源框架执行，登录、课程列表和答题页不主动载入。内置的是运行该特定 @grant none 脚本的支持，不是完整的 Tampermonkey 扩展，不支持任意用户脚本或 GM API。脚本及依赖已固定版本随包提供，不从远程自动更新。

播放加速不等于平台必定认可学时；程序仍等平台目录确认完成，不伪造进度、不跳到视频结尾。网站可能限制速度或按服务端时间计时。此版未完成真实课程、Windows/Mac 实机验收。

## 安装

Windows：双击 Setup EXE，按向导安装。Mac M 系列：解压 mac-arm64.zip，将 .app 拖到 Applications；要求 macOS 13+。Mac 为 ad-hoc 签名，未通过苹果公证。若系统阻止打开，按系统的隐私与安全设置处理，不需要关闭系统安全功能。

升级默认沿用原有设置、队列、登录会话和本机加密密钥。跨系统或换用户后需重新登录并配置密钥。先退出旧版，再安装或替换应用。源代码、第三方声明和许可随源码 ZIP 提供，详见 THIRD_PARTY_NOTICES.md。

## 构建和测试

```sh
npm ci
npm test
npm run dist:win
# 在 Mac 构建 Apple Silicon 版本
npm run dist:mac
```

Linux 交叉构建 Mac 时，TONGJI_RCODESIGN 必须指向 rcodesign。签名脚本会验证代码页及资源哈希；静态检查不等于苹果 Gatekeeper 或实机验收。

# 同学堂助手桌面版 v0.2.4

Windows 10/11 x64 桌面应用，内置课程浏览器，安装后不需要 Python、浏览器扩展或单独的后台服务。

## 安装与首次使用

1. 下载并双击 `Tongxuetang-Assistant-Setup-0.2.4-x64.exe`，按安装向导完成安装，可选安装目录。默认安装到当前用户，无需管理员权限。
2. 从桌面或开始菜单打开“同学堂助手”。
3. 在“02 AI 设置”选择 DeepSeek 或 OpenAI，填写自己的 API 密钥，勾选“使用本机系统加密记住密钥”，点击“保存设置”。
4. 点击“测试 AI 连接”。这会向所选服务商发送一次实际 API 请求，按服务商的 API 用量收费。
5. 点击“打开高等讲堂”，在软件弹出的课程窗口中登录同学堂；遇到统一认证请自己扫码。
6. 回到助手主窗口读取课程列表，勾选课程后开始。

首次保存后，后续打开会恢复服务商、模型、课程资料、请求上限、自动交卷选项、课程队列和运行记录。密钥不需要每次重填。退出时任务会暂停，重新打开后点击“继续”。

## 密钥和登录状态如何保留

- Windows 上使用 Electron safeStorage，底层由 Windows DPAPI 加密密钥；设置文件只保存加密后的数据，不保存明文密钥。应用主进程读取密钥，不把密钥返回给课程网页或显示设置的网页。
- 加密密钥与当前 Windows 用户/系统环境有关，复制设置到其他电脑或其他账户后可能无法解密，需要重新填写。这也无法防御已控制你 Windows 账户的恶意程序。
- 若取消“加密记住密钥”并输入密钥，只在本次进程使用，关闭后不会保留。加密服务不可用时会明确报错，不会自动降级为明文保存。
- 设置保存在 `%APPDATA%\Tongxuetang Assistant\settings.json`，点击“打开数据目录”可查看位置。OpenAI 和 DeepSeek 的密钥分别保存。
- 内置课程窗口的 Cookie 和登录数据使用持久会话。它与原来 Edge/Chrome 的登录会话独立，第一次需要在软件里登录；学校使登录失效后仍需要重新认证。
- 重装/升级默认保留用户数据。卸载默认也保留设置；如需彻底清理，请在卸载后自行删除上述数据目录。
- 本版不监听本机 HTTP 端口，不使用连接口令，也不要求启动 BAT 文件。

## 课程与 AI 行为

沿用 v0.1.0 已适配的同学堂页面结构，按首页预设倍速播放视频，读取同源 iframe 中的题干和选项。优先使用题干末尾的有效答案提示，无提示题使用缓存或请求 AI。题目、选项、课程资料和可读取字幕会发送给所选 API 服务商。没有音轨转录功能，不能声称 AI 已经听过整段视频。

自动交卷默认开启，可以在设置关闭。答案缺失、编号或选项不匹配、异常页面和平台未确认任务完成时会暂停；有效格式不保证答案正确。默认开启自动加入学习；遇到协议、付款或额外认证时暂停并由你手动处理。图片题、跨域播放器和其他未适配题型可能无法处理。

## 版本与验证范围

这是桌面修复测试版，已构建真正的 Windows NSIS EXE 安装程序，包含 x64 Electron/Chromium 运行环境；安装程序主体使用 Windows 可兼容的 32 位 NSIS 引导器，安装的应用是 64 位。

自动化测试覆盖设置与队列在重启后恢复、密钥存储边界、两个 AI 服务商、答案校验、防止重复提交、模拟完整任务流。Linux 下实际启动桌面窗口进行界面/页面适配联调。Windows DPAPI 和安装后的 Windows 实机行为仍需实际 Windows 验收；本环境不是 Windows。未使用真实 API 密钥，不把模拟返回当作真实云端调用成功。正式课程从视频到最终交卷的完整线上验收仍待完成。

安装包暂未使用发布者代码签名证书，Windows 可能显示“未知发布者”或信誉提示。不要关闭系统安全防护；如设备禁止运行未签名程序，需要签名版本或设备管理员处理。

与同济大学或 API 服务商没有官方关联。

## 开发与构建

源码压缩包包含独立桌面项目，不需要原插件项目。开发工具需要 Node.js 22+：

```sh
npm ci
npm test
npm start
npm run dist:win
```

`dist:win` 会生成 Windows x64 NSIS 安装包，默认不自动发布。Windows 下使用正常的 electron-builder 流程；Linux 下对固定版本打包器复用其内置 NSIS 卸载器读取功能，避免运行中间 Windows 卸载器。生产包不包含测试工具，也不包含 API 密钥。

若要发布公开版本，请先完成 Windows 实机和站点兼容性验收，并使用自己的代码签名证书。API 请求仍需用户自己的有效密钥及可用额度。
