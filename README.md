# 同学堂助手桌面版 v0.2.1

Windows 10/11 x64 桌面应用，内置课程浏览器，安装后不需要 Python、浏览器扩展或单独的后台服务。

## 安装与首次使用

1. 下载并双击 `Tongxuetang-Assistant-Setup-0.2.1-x64.exe`，按安装向导完成安装，可选安装目录。默认安装到当前用户，无需管理员权限。
2. 从桌面或开始菜单打开“同学堂助手”。
3. 在“02 AI 设置”选择 DeepSeek 或 OpenAI，填写自己的 API 密钥，勾选“使用本机系统加密记住密钥”，点击“保存设置”。
4. 点击“测试 AI 连接”。这会向所选服务商发送一次实际 API 请求，按服务商的 API 用量收费。
5. 点击“打开高等讲堂”，在软件弹出的课程窗口中登录同学堂；遇到统一认证请自己扫码。
6. 回到助手主窗口读取课程列表，勾选课程后开始。

首次保存后，后续打开会恢复服务商、模型、课程资料、请求上限、自动交卷选项、课程队列和运行记录。密钥不需要每次重填。退出时任务会暂停，重新打开后点击“继续”。

## 密钥和登录状态如何保留

- Windows 上使用 Electron safeStorage，底层由 Windows DPAPI 加密密钥；设置文件只保存加密后的数据，不保存明文密钥。应用主进程读取密钥，不把密钥返回给课程网页或显示设置的网页。
- 加密密钥与当前 Windows 用户/系统环境有关，复制设置到其他电脑或其他账户后可能无法解密，需要重新填写。这也无法防御已控制你 Windows 账户的恶意程序。
- 若取消“加密记住密钥”并输入密钥，只在本次进程使用，关闭后不会保留。加密服务不可用时会明确报错，不会自动降级为明文保存。
- 设置保存在 `%APPDATA%\Tongxuetang Assistant\settings.json`，点击“打开数据目录”可查看位置。OpenAI 和 DeepSeek 的密钥分别保存。
- 内置课程窗口的 Cookie 和登录数据使用持久会话。它与原来 Edge/Chrome 的登录会话独立，第一次需要在软件里登录；学校使登录失效后仍需要重新认证。
- 重装/升级默认保留用户数据。卸载默认也保留设置；如需彻底清理，请在卸载后自行删除上述数据目录。
- 本版不监听本机 HTTP 端口，不使用连接口令，也不要求启动 BAT 文件。

## 课程与 AI 行为

沿用 v0.1.0 已适配的同学堂页面结构，正常速度播放视频，读取同源 iframe 中的题干和选项。优先使用题干末尾的有效答案提示，无提示题使用缓存或请求 AI。题目、选项、课程资料和可读取字幕会发送给所选 API 服务商。没有音轨转录功能，不能声称 AI 已经听过整段视频。

自动交卷默认开启，可以在设置关闭。答案缺失、编号或选项不匹配、异常页面和平台未确认任务完成时会暂停；有效格式不保证答案正确。尚未加入学习的课程需要你在网站手动加入。图片题、跨域播放器和其他未适配题型可能无法处理。

## 版本与验证范围

这是桌面修复测试版，已构建真正的 Windows NSIS EXE 安装程序，包含 x64 Electron/Chromium 运行环境；安装程序主体使用 Windows 可兼容的 32 位 NSIS 引导器，安装的应用是 64 位。

自动化测试覆盖设置与队列在重启后恢复、密钥存储边界、两个 AI 服务商、答案校验、防止重复提交、模拟完整任务流。Linux 下实际启动桌面窗口进行界面/页面适配联调。Windows DPAPI 和安装后的 Windows 实机行为仍需实际 Windows 验收；本环境不是 Windows。未使用真实 API 密钥，不把模拟返回当作真实云端调用成功。正式课程从视频到最终交卷的完整线上验收仍待完成。

安装包暂未使用发布者代码签名证书，Windows 可能显示“未知发布者”或信誉提示。不要关闭系统安全防护；如设备禁止运行未签名程序，需要签名版本或设备管理员处理。

与同济大学或 API 服务商没有官方关联。

## 开发与构建

源码压缩包包含独立桌面项目，不需要原插件项目。开发工具需要 Node.js 22+：

```sh
npm ci
npm test
npm start
npm run dist:win
```

`dist:win` 会生成 Windows x64 NSIS 安装包，默认不自动发布。Windows 下使用正常的 electron-builder 流程；Linux 下对固定版本打包器复用其内置 NSIS 卸载器读取功能，避免运行中间 Windows 卸载器。生产包不包含测试工具，也不包含 API 密钥。

若要发布公开版本，请先完成 Windows 实机和站点兼容性验收，并使用自己的代码签名证书。API 请求仍需用户自己的有效密钥及可用额度。

## v0.2.1 修复

- 识别“批阅完成”“已通过本次考试”和成绩汇总表，保留旧题目/按钮的成绩页也优先当作结果页。
- 成绩页返回课程目录核对平台进度；只在目录明确显示任务全部完成后推进课程。
- 下一门课程使用新课程窗口；新窗口加载成功后关闭助手原来的课程窗口。打开失败会暂停并保留旧窗口。
- 等待页面及目录控件加载，避免桌面预加载脚本过早读取空目录并暂停。
- 点击“开始”先保存当前设置。队列显示勾选数量、课程上限与本次实际运行数量；正在运行的计划不会因后续勾选自动扩展。
- 升级保持同一应用标识、用户目录与设置格式。先退出旧版本，再运行新安装包；不要删除数据目录。
- 若旧计划显示“课程 1/1”，请调整课程上限、勾选目标课程并点击“开始”创建新计划；“继续”会恢复原计划。
