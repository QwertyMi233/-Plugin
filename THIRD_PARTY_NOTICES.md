# Bundled userscript and dependencies

The application provides a limited built-in userscript runner for the following @grant none script. It does not contain the Tampermonkey extension and does not implement a general-purpose Tampermonkey/GM API environment.

- **TimerHooker / 计时器掌控者|视频广告跳过|视频广告加速器 1.0.62**, Cangshi, GPL-3.0-or-later (as declared by the original script). Original script, metadata and attribution are preserved in `src/vendor/timer-hooker.user.js`. License: `src/vendor/COPYING-TimerHooker`. Source: https://greasyfork.org/en/scripts/372673 . The separate application adapter restricts execution to same-origin video frames of Tongxuetang course task pages and maps the user's playback rate to the reciprocal timer percentage. Disabling resets the script to 1x; reload completely removes its hooks. No remote automatic updates.
- **Everything-Hook 0.5.9056**, Cangshi, Apache License 2.0 according to the upstream hooker-js repository, with the upstream license preserved in `src/vendor/LICENSE-Everything-Hook`. Dependency is pinned to TimerHooker's original @require URL: https://greasyfork.org/scripts/372672-everything-hook/code/Everything-Hook.js?version=881251 . Upstream: https://github.com/canguser/hooker-js . GreasyFork itself lists this dependency's license as N/A; upstream package metadata and LICENSE were consulted.

SHA-256 hashes of the original bundled JavaScript files are in `src/vendor/manifest.json`. The downloadable source archive provides the complete application and adapter source, original userscript and dependency, licenses, tests and build scripts, excluding generated binaries and development dependencies. The application source remains under its existing MIT license; the bundled third-party files retain their respective licenses. Electron/Chromium notices accompany the packaged runtime.
