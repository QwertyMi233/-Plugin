同学堂助手 v0.2.4 · Apple 芯片 Mac 版

安装：
1. 下载 Tongxuetang-Assistant-0.2.4-mac-arm64.zip。
2. 双击 ZIP 解压，得到 Tongxuetang Assistant.app。
3. 将 .app 拖入“应用程序”（Applications）文件夹，再打开。
4. 本版做了本地 ad-hoc 签名，但没有 Apple Developer ID 签名和苹果公证。若 macOS 阻止运行，请按系统提示处理；受管理的电脑请联系管理员。不要关闭系统安全防护。

首次使用：
1. 在 AI 设置里选择服务商，填写自己的 API 密钥和可用模型，保存后测试连接。
2. 点击“打开高等讲堂”，在内置课程窗口扫码登录。
3. 读取课程或粘贴链接导入，设置本次课程数量，勾选后点击“开始”。
4. 保留 v0.2.4 的自动加入学习、视频播放、答题与交卷及课程切换功能。

Mac 的配置：
- 设置及课程队列默认保存在：
  ~/Library/Application Support/Tongxuetang Assistant/
- 可在软件中点击“打开数据目录”查看。
- 记住密钥使用 macOS 钥匙串。首次访问或升级时可能出现系统授权提示；只在 Mac 自己的系统对话框操作，不要把系统密码发送给他人。
- Windows 的加密密钥不能直接搬到 Mac。首次在 Mac 使用时，需要重新填写 API 密钥并登录学校网站。
- 没有付费开发者签名，本地签名不能保证每次升级都免除钥匙串重新授权。若密钥无法解密，重新填写保存即可。
- 支持 Command+C / V / X / A 和 Command+Q。
- 关闭助手主窗口会结束本次运行；重新打开后点击“继续”恢复原计划。
- 无需另外安装 Python、Node.js 或浏览器插件。

适用设备：
适用于 Apple Silicon（M 系列芯片），需要 macOS 13 或更新版本。不是 Intel 版，不是 Windows EXE。

验证说明：
已进行代码回归和安装包结构检查。本环境不是 Mac，未实际启动 macOS 应用，尚未验证 Mac 钥匙串、扫码登录及完整课程流程。请先用一门课程试运行。

新增视频倍速：首页选择 0.25–16 倍，点击保存并应用；后续视频自动使用。计时器掌控者已内置，需要时勾选开关；默认只改变视频倍速，不改变计时器。恢复正常播放会保存 1 倍并关闭脚本，刷新课程页完全卸载脚本。
