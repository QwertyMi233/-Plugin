同学堂助手 · 联网 AI 版 · v0.1.0 测试版

先装插件，再连接 AI

这是 Windows 上 Edge / Chrome 的扩展安装包。请先完整解压压缩包，再按下面顺序操作。

需要 Python 3.10+ 和你自己的 OpenAI API 密钥。API 使用单独计费，本版没有实现 ChatGPT 订阅登录。

1．把扩展装进浏览器

  1. Edge 地址栏输入 edge://extensions，Chrome 输入 chrome://extensions。
  2. 打开开发人员模式，点击加载解压缩的扩展。
  3. 选择本安装包的 extension 文件夹。应能在里面看到 manifest.json，不要选择 ZIP 或最外层文件夹。
  4. 点击浏览器右上角扩展菜单，打开“同学堂助手”。之后的设置和运行状态都在这个页面。

2．启动本机 AI 服务

  1. 如果没有 Python，请从 Python 官网安装 Python 3.10 或更新版本，安装时勾选 Add Python to PATH。不需要额外安装 Python 包。
  2. 双击解压文件夹里的 start-windows.bat，保持出现的黑色窗口打开。
  3. 自动打开的配置页中填写自己的 OpenAI API Key，再保存。密钥从 OpenAI API 控制台管理。不要填写学校密码。
  4. 在该页点击复制连接口令，回插件粘贴到“本机服务连接口令”，点击保存设置。
  5. 依次点击检查本机连接和测试云端 AI。云端测试会实际发出一次 API 请求。

3．选择课程并开始

  1. 在装有扩展的同一浏览器登录同学堂。遇到统一认证，由你完成扫码。安装前已打开的页面，请刷新一次。
  2. 在插件点击打开高等讲堂，选择网站的“全部”分类。
  3. 回插件点击读取当前页或读取当前筛选全部页，勾选课程。
  4. 点击开始所选课程。默认一次最多 3 门课；自动交卷默认开启，可以在设置调整。
运行流程
正常播放视频 → 核对平台进度 → 识别试题 → 读取有效答案提示，无提示时请求 AI → 校验并填写 → 交卷 → 核对任务完成 → 下一门课

运行时留意

  • 保持浏览器、课程标签和服务窗口打开，电脑不要休眠。
  • 若浏览器阻止自动播放，手动点一次播放，再回插件点击“继续”。
  • 尚未加入的课程会暂停，请在网站手动加入学习，再点击“继续”。
  • 每次重启服务，都需要在配置页重新填写 API 密钥。密钥默认只存在本次进程的内存中。
  • 题目、选项、粘贴的资料及可读取字幕会发送给 OpenAI。插件没有音轨转录功能；AI 不等于实际听过完整视频。
  • AI 答案仍可能有误；可以关闭自动交卷，检查答案后手动交卷。异常、漏答或无效选项会暂停。
