这里填连接口令，OpenAI API 密钥只在本机服务页填写。

题目、选项、资料及可读取的字幕会发送给 OpenAI。模型回答仍可能有误；不确定或格式异常时暂停。

云端测试会产生一次 API 请求。API 费用单独结算。

运行流程

你登录 → 读取并选择课程 → 正常播放视频 → 核对平台进度 → 识别题目 → 优先使用题干答案提示，无提示时请求 AI → 校验并填写 → 自动交卷 → 再次核对任务 → 下一门课程。

新课程需要加入学习时会暂停，由你在网站操作。首次播放若被浏览器拦截，请手动点一次播放后继续。保持浏览器和服务窗口打开，电脑不要休眠。
